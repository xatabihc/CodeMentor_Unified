# CodeMentor 2.0 — Ubuntu + Android (единая кодовая база)

Это **работающий офлайн-тренажёр** с интерфейсом на русском языке. В архиве:

- `www/` — одна общая веб-версия (PWA) для ноутбука и мобильного устройства;
- `android-studio/` — исходный проект Android Studio, который встраивает те же уроки локально в APK;
- `run-ubuntu.sh` — запуск под Ubuntu без установки зависимостей через Python HTTP-сервер;
- `install-ubuntu.sh` — ярлык в меню приложений;
- `tools/export_old_progress.py` — перенос SQLite-прогресса CodeMentor 1.0–1.6;
- `tools/sync_android.py` — синхронизация исходников WebView с Android;
- `tools/test_runner.js` — проверка эталонных решений 32 начальных уроков (для разработчика).

## Что работает

- **166 уроков**, перенесённых из CodeMentor 1.6 (путь с нуля, Python, MOOC, Linux, SQLite, исправление ошибок, мини-проекты, классы/файлы).
- 32 последовательных урока «С нуля»: новая тема и пример, практика, автопроверка по тестовым примерам, подсказки, открытие следующего урока после правильного ответа.
- Проверка *некоторых* дополнительных Python-заданий через учебный JS-поднабор Python, статическая проверка Linux-команд, текстовая проверка десяти SQL-упражнений по образцу. **Полный CPython, выполнение SQL-запросов на настоящей учебной базе и автоматическая проверка всех 166 упражнений в мобильной версии пока не реализованы.** Эти уроки можно читать и редактировать, черновики сохраняются.
- Автосохранение черновиков, пройденных уроков и попыток в локальном хранилище устройства.
- Экспорт/импорт JSON-прогресса между Ubuntu, Android и предыдущими версиями. Синхронизации без явного переноса файла нет.
- Работа без интернета после установки; без учётной записи и серверной базы данных.
- Адаптивный интерфейс, прокрутка на мобильном и настольном экранах, поддержка Ctrl+Enter и Tab в редакторе.

> **Важно:** выполнение учебного Python — не CPython. Код транспилируется внутри отдельного Web Worker и прерывается по времени. Это не универсальная песочница для недоверенного кода. Не вводи в неё секреты, ключи доступа или код, полученный из ненадёжных источников.

## Запуск на Ubuntu

Скачай ZIP в `~/Загрузки`, затем:

```bash
sudo apt install -y python3 unzip
mkdir -p ~/Программы
cd ~/Загрузки
unzip -n CodeMentor_2.0_Ubuntu_Android.zip -d ~/Программы
cd ~/Программы/CodeMentor_Unified
./run-ubuntu.sh
```

Откроется (или открой вручную) **http://127.0.0.1:8765/**. Не закрывай терминал, пока пользуешься программой. `Ctrl+C` остановит локальный сервер. Чтобы получить ярлык в меню Ubuntu:

```bash
./install-ubuntu.sh
```

Для установки PWA в Chrome: открой страницу и используй меню браузера «Установить приложение» (если поддерживается).

## Сборка Android APK в Android Studio на Ubuntu

**Готового APK в этом архиве нет.** Android SDK/Gradle и Android Studio отсутствуют в среде, где готовился архив, поэтому компиляция APK здесь не проверена. Код и ресурсы для сборки включены.

1. Установи актуальный **Android Studio** с Android SDK (понадобятся JDK/Gradle, Android Studio настроит их при синхронизации) и открой в Android Studio папку `CodeMentor_Unified/android-studio` через **Open**.
2. Дождись **Gradle Sync**, подтвердив загрузку Android Gradle Plugin и AndroidX WebKit. Для первой сборки нужен интернет на ноутбуке.
3. Через `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)` собери отладочный APK.
4. APK появится по пути `android-studio/app/build/outputs/apk/debug/app-debug.apk`.
5. Передай файл на свой Android и установи его, разрешив установку из выбранного источника в настройках Android.

Если меняешь уроки или интерфейс (`www/`), перед очередной сборкой запусти:

```bash
cd ~/Программы/CodeMentor_Unified
python3 tools/sync_android.py
```

**Android-ограничения:** minSdk 26 (Android 8+); целевая версия SDK 35. Android приложение использует `WebViewAssetLoader`, Web Workers и LocalStorage. Разрешение доступа в интернет в манифесте отсутствует. Внешние учебные ссылки открываются через системный браузер.

Если IDE предлагает обновить Android Gradle Plugin, сначала создавай отдельную копию проекта. Для публикации в магазине нужен собственный ключ подписи и дополнительное тестирование на телефоне.

## Перенос прогресса из CodeMentor 1.6

**Не удаляй старую программу.** Закрой её и сделай копию файла `~/.local/share/codementor/progress.sqlite3`.

```bash
cd ~/Программы/CodeMentor_Unified
python3 tools/export_old_progress.py -o old-progress.json
```

В новом CodeMentor выбери **⚙ → Импорт JSON**, укажи `old-progress.json`. Чтобы перенести результаты на Android, скопируй JSON на телефон и импортируй там. Импорт не стирает уже пройденные уроки.

В новой версии для экспорта есть **⚙ → Экспорт прогресса**. На Android откроется системное окно сохранения документа; на Ubuntu — скачивание JSON через браузер.
