Дата: 2 ноября 2026. Исходный Git HEAD записан в резервной копии.

## Фактическое состояние до изменений

Чистая ветка main. Android: 2.1.0-dev-nav1 / 211. Локально 170 уроков:
path 36, python 30, mooc 28, linux 26, advanced 17, projects 15, sql 10, debug 8.
Каталог с 221 уроком отсутствует. Все 170 ID сохраняются без изменений.

Ubuntu запускает общий фронтенд www через локальный Python HTTP-сервер.
Android встраивает копию фронтенда в WebView через WebViewAssetLoader.
Источник учебных материалов — curriculum_source/codementor; export_courses.py
генерирует lessons.js, исключая эталоны Python. sync_android.py переносит ресурсы.
Android applicationId com.codementor.offline и origin
https://appassets.androidplatform.net/assets/ сохраняются.

Прогресс: ключ codementor-unified-v1, JSON v1, records с draft, completed,
attempts, hint_level, completed_at. Android дублирует данные в приватных
SharedPreferences; сохраняются резервные читаемые записи и saved_at.
Импорт объединяет записи, сохраняет неизвестные ID и существующие черновики.
SQLite 1.x экспортируется отдельным инструментом. Данные установленных
браузеров/телефонов недоступны из репозитория и не копировались.

Резервная копия до изменений: backups/before-3.0-20261102-150832:
sources.tar.gz, progress-schema.js, git-head.txt, checksums.json.
Архив содержит отслеживаемые исходники, не кеши, ключи или личные базы.

## Готово в A

Три направления с отдельными счётчиками прогресса. Старые восемь разделов
сохранены внутри Python, включая Linux и SQLite. Направление сохраняется
в дополнительном поле course прежнего снимка v1; старые снимки поддерживаются.
Математические направления пока явно обозначены как готовящиеся.

Общая модель Course → Level → Module → Lesson → Exercise; прежнее задание
становится упражнением с тем же ID. Все шесть уровней имеют стабильные ID.
Назначение уровней прежним урокам предварительное: path — с нуля,
advanced — продвинутый, остальные — базовый; это не новая педагогическая
разметка всего старого курса. Attempt → Result представлены общим API;
история отдельных попыток пока не сохраняется, старый счётчик сохраняется.

Числовой, матричный, векторный, статистический числовой и выборочный
обработчики с абсолютным/относительным допуском. Это инфраструктура;
новые математические уроки ещё не подключены. Алгебраические выражения
и пошаговые доказательства явно возвращают unsupported.

Офлайн service worker включает общий движок. Android 3.0.0-dev-a1 / 300:
applicationId, origin, minSdk, разрешения и исправления SafeArea не менялись.

## Изоляция и ограничения

106 уроков проверяются JS-поднабором Python, 36 — текстом, 28 недоступны.
Worker использует new Function после трансляции и regex-фильтрации.
Это не доказанная безопасная песочница: regex не является границей защиты.
Есть таймаут, лимиты строк/шагов/вывода; нет CPython, файловой системы
или AndroidBridge внутри worker. CSP запрещает connect-src, Android не имеет
INTERNET и блокирует внешние запросы WebView. Память Worker не квотируется.
Системный Python не подключался к пользовательскому редактору.

## Следующие отдельные этапы

B: первый полный модуль матриц, визуальный ввод, реальная проверка,
пошаговые операции; затем векторы и последующие уровни.
C: описательная статистика и локальные графики, затем вероятность и вывод.
D: разбор всех 14 частей MOOC и оригинальные русские упражнения.
E: объединение, проверка обновления на устройстве, APK.
Адаптивное повторение, закладки, поиск, темы и локальный рендерер формул
пока не реализованы. Не считать наличие пустого уровня готовым курсом.

Сверены исходная страница https://programming-26.mooc.fi/,
каталог https://programming-26.mooc.fi/all-exercises/ и репозиторий
https://github.com/rage/programming-26. Каталог упражнений загружается
динамически; его полный состав пока не изучен. Университетские тексты,
решения и тесты не переносились. Перед адаптацией нужна отдельная
проверка лицензии и атрибуции; официальный статус CodeMentor не заявляется.
