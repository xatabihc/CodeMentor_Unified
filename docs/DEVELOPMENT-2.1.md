## Android-сборка: результат текущей сессии

Выполнена команда:

```bash
GRADLE_USER_HOME="$PWD/.gradle-local" bash tools/build-apk.sh --offline --stacktrace
```

Gradle стартует, но не доходит до конфигурации Android-проекта: создание FileLockContentionHandler завершается ошибкой `Could not determine a usable wildcard IP for this machine`, корневая причина — `java.net.SocketException: Operation not permitted (Socket creation failed)` при чтении сетевых интерфейсов. Offline и no-daemon не устраняют потребность Gradle в локальных сокетах.

Попытка запросить расширенный запуск сборки отклонена автоматически политикой среды (`sandbox_approval: false`). Запросить его через окно подтверждения в этой сессии невозможно. Версии зависимостей из-за этой ошибки не менялись. Системные ограничения не обходились.

ADB снова не смог запустить listener (`Operation not permitted`); наличие подключённого устройства не установлено. Java MainActivity компилируется против Android 35 и WebKit 1.12.1, но это не проверяет выполнение Activity и не заменяет assembleDebug.

**Успешный assembleDebug, lintDebug, запуск APK, клавиатура, поворот и реальное обновление приложения пока не подтверждены.**

## Что подготовлено для доступной сборочной среды

- build-apk.sh экспортирует актуальные уроки, синхронизирует ресурсы, вызывает Wrapper и после успешной сборки запускает проверку реального APK.
- В Gradle добавлена цепочка preBuild -> syncWebAssets -> exportCourses: даже запуск из Android Studio сначала экспортирует Python-каталог. Нужен python3; другой путь можно передать через `-PpythonExecutable=/путь/к/python`.
- check_apk.py проверяет manifest/DEX, точный набор и содержимое всех assets, ID каталога и отсутствие Python-эталонов. Обнаруживает устаревший worker.js и лишние старые assets. Его три теста используют ZIP-фикстуры — это не тесты настоящего APK.
- Проверка APK явно сообщает о Python-компонентах: учебный worker.js включён; CPython, исполняемые .py и нативный Python runtime не добавлялись. Python-источники учебника экспортируются в lessons.js без эталонных решений.

```bash
bash tools/test.sh
bash tools/build-apk.sh
cd android-studio
./gradlew --no-daemon lintDebug
```

В этой сессии первые проверки доступны, остальные ограничены окружением. После получения настоящего APK необходимы сценарии UPDATE.md.

## Разбор 28 неподдержанных уроков

| ID | Причина отсутствия веб-проверки |
|---|---|
| py19, py26, mooc07 | Срез с обратным шагом `[::-1]` |
| py20, py24, mp13, mooc19, mooc20 | Целочисленное деление `//`; в JavaScript это начало комментария |
| py21 | Отрицательные индексы; JS не применяет правила индексации Python |
| py25 | Проверка вхождения `in`; JS имеет другую семантику |
| mooc14 | Кортежи; выражение `(x, y)` в JS не создаёт кортеж |
| adv01–adv08 | Классы, конструкторы, состояние, методы, связанные объекты |
| adv09–adv11 | Чтение, запись и добавление в TXT |
| adv12–adv13 | CSV и файлы |
| adv14–adv15 | Модуль json и файлы |
| adv16–adv17 | Классы совместно с файлами и JSON/текстом |

Существующие ID, задания и эталоны этих уроков не удалены. Все 28 помечены `checking.mode=unavailable`, кнопка отключена, Ctrl/⌘+Enter не запускает Worker и не увеличивает число попыток. Причина видна возле редактора. Теория, подсказки, черновик и ранее сохранённое прохождение остаются доступны. Урок без подтверждённых метаданных также не получает автоматическую проверку.

Остальные режимы: `python-subset` — учебный поднабор Python; `text` — текстовое сопоставление Linux/SQL без запуска. Режимы формируются из Python-источника, проверка эталонов всех объявленных `python-subset` входит в test.sh. Успешный эталон не доказывает поддержку произвольной программы или изоляцию.

## Обучение и редактор

Каталог теперь содержит **170 уроков**, начальный маршрут — **36**. Все прежние 166 ID и их разделы/порядок закреплены в compatibility/2.0.1-lesson-ids.json и проверяются тестом.

Добавлены path33–path36: остаток, чётность, функция для остатка, контрольная упаковка подарков. Только одна новая операция `%`; остальные шаги повторяют ввод, условия и функции. Условия задач явно ограничены целыми неотрицательными значениями и положительным делителем. Это соответствует проверяемому поднабору и не обещает семантику отрицательного остатка JS как в Python.

У каждого нового урока есть жизненный пример, построчный разбор, первый шаг, средняя и самостоятельная практика, типичные ошибки, повторение и контроль. Дополнительная практика явно обозначена как самопроверка; автоматическая кнопка относится только к основному заданию. Тексты и задачи созданы самостоятельно; прежние ссылки Helsinki MOOC сохранены.

Редактор поддерживает автоматические отступы после двоеточия, пары скобок, Tab, Ctrl/⌘+Enter. События незавершённого ввода IME не перехватываются. Ошибки неопределённой переменной и синтаксиса получают русские объяснения без готового решения. Это всё ещё textarea, а не полноценная IDE с подсветкой и несколькими файлами.

Навигация учитывает динамическую высоту экрана, доступна прокрутка короткой боковой панели; снято ограничение высоты теории. Мобильный редактор использует шрифт 16px, кнопки — минимум 44px; добавлена видимая рамка клавиатурного фокуса. Проверены логика редактора и DOM-имитация; реальная Android-раскладка требует проверки на устройстве.

## Сохранность прогресса

- Ключ codementor-unified-v1, applicationId и экспорт JSON v1 сохранены. При импорте остаются неизвестные локальному каталогу ID.
- LocalStorage и приватные SharedPreferences сохраняют предыдущую читаемую запись как резервную. Это локальная копия, не замена отдельного экспортированного JSON.
- Внутренний saved_at позволяет выбрать более свежую читаемую копию, если запись в Android не удалась после успешной записи в браузер. Старые записи без saved_at поддерживаются; экспортируемый JSON не меняется.
- Перед восстановлением записи проверяются. Если все существующие копии повреждены, автоматическая запись приостанавливается, чтобы не заменить их пустыми данными. Пользователь может сохранить текущую работу экспортом или явно импортировать проверенный JSON.
- Импорт сообщает, если данные остались лишь в памяти из-за ошибки записи. Дубликаты, неверные типы и версии отклоняются до объединения.
- Исправлена обработка специального неизвестного ID __proto__: это собственная запись словаря, а не изменение прототипа.

## Проверенный результат

`bash tools/test.sh`: 170 уникальных уроков и одинаковые Android assets; совместимость прежних ID; **36** эталонов и **36** незавершённых шаблонов маршрута; **106** эталонов в веб-движке и **28** явно недоступных; **332** случая эталонов в CPython без ошибок; проверки редактора, прогресса и резервных копий, фактический перенос SQLite 1.x в JSON и новый импорт; три проверки ZIP-упаковки; синтаксис JS/shell.

CPython здесь запускает только доверенные эталоны разработчика в временных каталогах проекта. Он не подключён к редактору, и временный каталог не является безопасной песочницей.
