# D1 — оригинальная практика Python для данных

3.0.0-dev-d1 / 306. Добавлены шесть коротких уроков py-data-01…06:
читаемый отчёт, сумма расходов, проверка лимита, накопление суммы,
частота положительных наблюдений, функция для размаха. Общий каталог
225 уроков; все прежние 183, B2 и C2 сохранены. Это первый модуль
расширения Python, а не реализация всех 14 частей университетского курса.

Каждый урок содержит объяснение, разобранный пример, простую и
самостоятельную практику, подсказки и типичные ошибки. Основное задание
имеет четыре поведенческих теста, включая нули/равенство/отрицательные
наблюдения или пределы ввода по смыслу задачи. Дополнительная практика
в тексте является самопроверкой; автооценка относится к основному заданию.
Предпосылки следующих уроков обязательны для зачёта, материалы можно
читать свободно. Закрытая проверка не увеличивает счётчик попыток.

В исходнике находятся два разных правильных решения для каждого урока.
Проверка принимает фактическое поведение, в частности варианты for/while,
противоположные ветвления и функцию/встроенные операции. Эталоны и
альтернативы не экспортируются в www/APK. Worker не расширялся системным
Python, файлами, импортами или нативным мостом. Неизменённые ограничения
JS-поднабора сохраняются; CPython запускает только доверенные эталоны
разработчика в тестах на Ubuntu, а не пользовательский код.

## Финальная физическая регрессия APK 306

Samsung SM-A075F: реальные свайпы во всех 11 разделах, новые панели B2,
раскрытые гистограмма/нормальная кривая/регрессия C2, отдельная прокрутка

Дополнительно независимый verify_progress.py сравнивает 24 записи из
резервной копии до обновления, включая completed_at и пустые черновики.

Тест нормализует оставшуюся IME до подключения DevTools и выбирает
координаты свайпа по видимой части WebView, а не по полному дисплею.
Это устраняет ложные отказы, когда жест попадал в клавиатуру либо Back
закрывал Activity, к которой уже подключён тест. Успешный отчёт:
.test-tmp/samsung-scroll/report.json. C2 отдельно: samsung-c2/report.json.
