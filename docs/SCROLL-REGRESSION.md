# Прокрутка: аудит и регрессия (2 ноября 2026)

Исходная версия: 3.0.0-dev-c1 / 302, 183 урока. Резервная копия:
backups/before-scroll-b2-20261102-155612. Все прежние ID дополнительно
закреплены в compatibility/3.0-c1-lesson-ids.json.

Причины: menu/sidebar содержал второй скроллер lesson-list, зависимый от
flex-высоты; теория сохранила overflow:auto и overscroll:contain после
снятия ограничения высоты; панели клиппировали содержимое overflow:hidden.
html/body использовали фиксированную высоту 100%. scrollIntoView для
текущего урока мог прокручивать предков за пределами самого меню.

Теперь документ владеет вертикальной прокруткой учебных экранов. Меню
имеет один независимый вертикальный скроллер. Код сохраняет собственную
прокрутку; широкие таблицы/матрицы прокручиваются внутри себя, позволяя
вертикальному жесту перейти странице. Длинные сообщения переносятся.
Диалог ограничен динамической высотой viewport и прокручивается целиком.
Приложение не перехватывает touchmove/wheel. Блокировка документа
nav-open применяется только при открытом модальном боковом меню и
снимается при закрытии/смене breakpoint; это не универсальное ограничение.

viewport.js реагирует на фокус и уменьшение visualViewport, раскрывая
обрезанное поле без изменения значения, выделения или скролла кода.
interactive-widget=resizes-content включён для поддерживающих браузеров.
Существующие Android adjustResize/SafeArea остаются: нативный контейнер
учитывает панели/вырез/IME без повторного HTML-padding. DevTools включён
явно только для debuggable APK, чтобы проверять настоящий WebView.

## Проверено

node tools/test_scroll.js: настоящий Chromium, 320×640, 360×800,
390×844, 412×915, 768×1024; десять разделов, wheel и touch-события,
достижимость нижней кнопки с hit-test, меню, длинный диалог, короткий
viewport при фокусе, код, матрица 8×8, отсутствие переполнения,
переходы и сохранённый черновик. Результаты .test-tmp/scroll-results.json.
Это CDP-тесты без Playwright: используется установленный Ubuntu ws.

Тот же тест с --baseline (стили исходного коммита 58e4449) воспроизводит
ошибку: последний урок меню находится на y=2006…2060 при высоте 640 и
недоступен после прокрутки внешнего меню. Новые стили проходят все размеры.

tools/test.sh проходит, assembleDebug успешен. APK 303 установлен через
adb install -r без очистки данных. Перед обновлением создана копия
приватных SharedPreferences и WebView: backups/samsung-before-scroll-20261102-160404,
15 записей прогресса, Samsung SM-A075F. На момент первичного теста
устройство показывает NotificationShade/lockscreen; реальные свайпы и IME
не подтверждены. Запрошена физическая разблокировка пользователя.
Не считать исправление полностью проверенным на Samsung до завершения
этого сценария. tools/device/test_scroll.js не сбрасывает данные и не
засчитывает учебные задания; сохраняет отчёт/снимки в .test-tmp.
