# CodeMentor 2.0

- Перенесены все 166 уроков CodeMentor 1.6 в общий JSON-каталог.
- Новый интерфейс для ноутбука и телефона (адаптивный PWA).
- Android Studio проект с WebViewAssetLoader (автономные ресурсы).
- Добавлен офлайн-движок проверки базового Python (Web Worker с лимитом времени).
- Сохранение черновиков, прохождения и попыток локально; импорт/экспорт прогресса.
- Скрипт переноса прогресса SQLite из версии 1.x.
- Добавлены тесты для последовательной учебной программы, мобильная вёрстка и прокрутка.

Не включено: APK-бинарник, полноценный CPython на Android, синхронизация между устройствами, AI-наставник, полное покрытие продвинутых уроков автопроверкой.
