# CodeMentor 3.0.0-dev-mooc26-themes (Android 308)

## Основа и авторские права

Программа тем соотнесена с [Python Programming MOOC 2026](https://programming-26.mooc.fi/) Университета Хельсинки. Введение занимает части 1–7, продвинутый курс — 8–14. [Каталог университетских упражнений](https://programming-26.mooc.fi/all-exercises/) можно открыть отдельно в браузере. CodeMentor не является официальным приложением университета.

Материалы оригинального университета распространяются по **CC BY-NC-SA 4.0**. В CodeMentor **не перенесены дословно** университетские лекции, задания, тесты или решения: на основе порядка тем подготовлены 98 собственных русскоязычных учебных блоков с бытовыми примерами, объяснениями ошибок, заданиями и вопросами. Их не следует выдавать за полный официальный набор заданий MOOC.

## Как устроен новый урок

1. Зачем тема нужна: конкретная бытовая задача или ситуация разработки.
2. Что означает конструкция Python — человеческими словами.
3. Небольшой пример кода.
4. Разбор результата по шагам.
5. Типичная ошибка и способ найти причину.
6. Самостоятельная задача на написание кода.
7. Вопрос на понимание с вариантами и конкретным объяснением после ошибки.
8. Возможность перейти дальше после прохождения проверки понимания.

Уроки связаны последовательными prerequisites — от первых команд до проектной работы. Необязательно сразу уметь решать сложную задачу: сначала разберись в примере и ответь на вопрос, затем напиши черновик и попробуй его в Python.

## Честные ограничения запуска Python

- **Вопросы на понимание проверяются офлайн** в CodeMentor.
- **Написанный код в новых уроках сохраняется как черновик.** Для частей, требующих настоящих модулей, файлов, ООП, регулярных выражений или Pygame, это **не автоматическая проверка Python**. Запускай код в установленном CPython на Ubuntu.
- Старые задания с подтверждённой поддержкой могут проверяться учебным JS-поднабором. Он **не является полноценным CPython**, поэтому ограниченные конструкции не выдаются за работающие.
- Для полноценной автоматической проверки новых 98 программных задач понадобится отдельная безопасная изолированная среда CPython и тесты решений. Это следующий инженерный этап, а не уже выполненная функция.

## Цветовые темы

В настройках представлены шесть оформлений: **синяя, красная, зелёная, фиолетовая, оранжевая и тёмная**. Выбор сохраняется отдельно в localStorage с ключом `codementor-ui-theme-v1`; данные и прогресс обучения не затрагиваются. Все стили находятся в `www/themes.css`, переключатель — `www/theme.js`. На Android используются те же офлайн-файлы.

## Проверка и сборка

- Исходники уроков: `curriculum_source/codementor/mooc26_core.json` и `mooc26_advanced.json`, генератор `content_mooc26_full.py`.
- Автоматические проверки: `python3 tools/test_mooc26.py`, `node tools/test_theme.js`, полный набор `bash tools/test.sh`.
- Gradle синхронизирует веб-ресурсы в Android и собирает APK.
- GitHub Actions проверяет уроки, Android lint, APK и публикует debug APK как артефакт при успешном результате.
- **Реальные экранные жесты и смену тем на Samsung нужно проверить с установленным APK**; сборка и DOM-проверки не заменяют тест на устройстве.
