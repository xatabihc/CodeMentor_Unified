## Архитектура и существующие функции

- curriculum_source/codementor: Python-данные уроков, собственные тексты, примеры, подсказки, эталоны и тестовые случаи. content.py объединяет остальные content_*.py.
- tools/export_courses.py экспортирует каталог без Python-эталонов. SQL-образцы включены, поскольку их использует текстовая проверка.
- www: общий интерфейс HTML/CSS/JS, адаптивная навигация, подсказки, последовательное открытие маршрута, черновики, попытки, прогресс, импорт/экспорт JSON v1, PWA и офлайн-кэш.
- www/worker.js: транслятор поднабора Python в JavaScript, new Function в Web Worker. Тайм-аут родителя 1,8 секунды. Это **не CPython и не подтверждённая безопасная песочница**. Жёсткого лимита памяти нет; регулярное выражение запрещённых конструкций не является изоляцией.
- Android: одна Activity, WebViewAssetLoader, WebChromeClient для выбора файлов и JavaScript bridge для экспорта и приватного прогресса. INTERNET в манифесте отсутствует. Упакованные ресурсы в app/src/main/assets.
- Linux-команды и SQL проверяются текстовым сопоставлением, а не настоящим исполнением. Подсветка синтаксиса, несколько файлов, полноценный traceback, AI, поиск и переключение тем пока отсутствуют. Ноутбук запускает ту же веб-версию через локальный HTTP-сервер.
- tools/export_old_progress.py читает SQLite старых версий в режиме ro и формирует JSON v1.
- install-ubuntu.sh создаёт ярлык вне проекта; в этой сессии не запускался.

## Ошибки и исправления

1. Скрипт сборки вызывал системный Gradle и игнорировал Wrapper. Исправлен; подготовка каталога и assets выполняется перед сборкой. preBuild также синхронизирует www при сборке в Studio.
2. Тесты требовали отсутствующий python и запускали его для каждого урока. Эталоны теперь передаются одним потоком от python3 в Node, без публикации в APK.
3. При восстановлении выбранного раздела открывался урок начального маршрута, не соответствующий разделу. Выбор первого незавершённого урока теперь учитывает восстановленный раздел. Пустой сохранённый черновик заменялся стартовым кодом; смена раздела могла пропускать сохранение. Исправлено.
4. Запоздавший ответ Worker отображал результат на другом уроке. Ответы для уже закрытого урока игнорируются.
5. Предыдущий импорт отвергал неизвестные ID, экспорт их отбрасывал. Теперь такие корректные записи сохраняются и экспортируются; некорректный импорт отклоняется до изменения данных. Дубликаты и неверные типы проверяются.
6. Android использовал только WebView LocalStorage. Добавлена приватная SharedPreferences-запись с подтверждением commit, прежний ключ codementor-unified-v1 читается при отсутствии новой записи. Формат JSON v1 сохранён.
7. Добавлены системные отступы для targetSdk 35, adjustResize, zoom и сохранение экземпляра WebView при обычном повороте. Требуют Android UI-проверки.
8. Необработанные удалённые запросы WebView/ServiceWorker блокируются, запросы к assets обслуживаются локально; навигация наружу разрешена только для HTTP(S) в системном браузере.
9. Эталон adv15 ожидал JSON с русскими буквами, но json.dumps по умолчанию их экранирует. Добавлен ensure_ascii=False; ID, задания и формат прогресса не менялись.
10. Добавлен .gitignore для настроек, ключей, пользовательских БД/JSON и сборок. **Git не инициализирован:** .git пуст и смонтирован только для чтения; git status сообщает «not a git repository». Системные и глобальные Git-настройки не менялись.

## Проверки и ограничения

- `bash tools/test.sh`: каталог 166 уникальных ID, одинаковые Android assets, отсутствие Python-эталонов в экспорте; 32 верных решения и 32 незавершённых стартовых шаблона; merge JSON, неизвестные ID, пустые черновики, атомарное отклонение ошибок; LocalStorage -> native bridge через имитацию; фактический экспорт временной SQLite 1.x и импорт JSON; 316 случаев эталонов в CPython; синтаксис JS/shell.
- CPython проверяет **доверенные эталоны разработчика** в временных каталогах с тайм-аутом, включая содержимое файлов. Это тестовый инструмент, не новый исполнитель пользовательского кода и не изоляция.
- Дополнительный отчёт `python3 tools/reference_solutions.py | node tools/worker_coverage.js`: из 130 уроков с Python-тестами эталоны проходят в веб-движке у 102. Оставшиеся 28: py19, py20, py21, py24, py25, py26, mp13, mooc07, mooc14, mooc19, mooc20, adv01–adv17. Даже прошедшие эталоны не доказывают корректную поддержку произвольных решений Python.
- MainActivity скомпилирована javac 17 против установленного Android 35 и WebKit 1.12.1. Это проверка Java, **не сборка APK**.
- Установлены JDK 17.0.20.1, SDK platforms android-35 и android-37.0, кэш AGP 8.13.2, Wrapper Gradle 8.13. Пара Gradle 8.13/JDK 17 соответствует [таблице AGP 8.13](https://developer.android.com/build/releases/agp-8-13-0-release-notes).
- Первая сборка остановилась на read-only домашнем Gradle-кэше. Копия дистрибутива в игнорируемом .gradle-local позволила запустить Gradle 8.13, затем он остановился: `Could not determine a usable wildcard IP for this machine`. Изменение версий эту ошибку окружения не исправляет.
- ADB не смог открыть listener: `Operation not permitted`. Наличие устройства не установлено. Chrome headless также остановлен запретом socket/setsockopt. UI, клавиатура, поворот, фактическое восстановление после убийства процесса и обновление APK не проверены.
- Контрольная сумма Wrapper-дистрибутива пока не закреплена: официальный endpoint недоступен из окружения. Версии инструментов закреплены, побитовая воспроизводимость APK не подтверждена.
